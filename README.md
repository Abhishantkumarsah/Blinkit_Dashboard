# Blinkit Sales Analysis Dashboard | Power BI

## 1. Project Overview

This project focuses on analyzing Blinkit's sales performance using Microsoft Power BI.

The objective was to transform raw grocery sales data into an interactive dashboard that helps users explore sales performance across different product categories, outlet types, outlet sizes, and outlet locations.

The dashboard provides a consolidated view of key performance indicators (KPIs) and business metrics to support data-driven decision-making.

## 2. Business Requirements

The primary objective of this project was to understand sales performance and explore how different product and outlet characteristics relate to business results.

The key business questions addressed in this project were:

- What are the total sales and average sales?
- How many items are represented in the dataset?
- What is the average customer rating?
- Which item types contribute the most to total sales?
- How do sales compare across outlet sizes?
- How does outlet location tier relate to sales performance?
- How do different outlet types compare in terms of sales and item count?
- How have sales varied across outlet establishment years?
- How do sales compare between low-fat and regular products?

## 7. Key Insights

The dashboard provides several observations about sales performance.

### 1. Outlet Type Performance

Supermarket Type1 records approximately $787.55K in sales, making it the largest sales contributor among the outlet types displayed.

### 2. Outlet Location Performance

Tier 3 outlets show approximately $472.13K in sales, compared with $393.15K for Tier 2 and $336.40K for Tier 1.

### 3. Fat Content Analysis

The dashboard compares sales from low-fat and regular products, helping users examine their respective contributions to total sales.

### 4. Product Category Analysis

The item type chart enables users to compare sales contributions across grocery product categories.

### 5. Sales Trends

The establishment-year chart allows users to examine how recorded sales vary across outlet establishment years.
